NextUI my282 SSH diagnostic tool

Launch once to start SSH and launch again to stop it. The status log is stored
at .userdata/my282/logs/ssh.txt. Login is spruce / happygaming on port 22.

The bundled dropbearmulti is the A30-tested Dropbear 2025.88 build from
spruceOS/spruce/bin/SSH/bin/dropbearmulti. Dropbear is distributed under the
MIT-style license included with its source project:
https://github.com/mkj/dropbear

This is a development diagnostic service. Do not leave it enabled on an
untrusted network.
